# 湘江 2035 · 河段机位配色文件

把 `xiangjiang-river-day-layers.svg`（日间）和 `xiangjiang-river-night-layers.svg`（夜间）从文件夹拖进 Figma。两张图都是 2160 × 1350，镜头、地理范围和图层编号一致，建议左右并排比较。`palette-reference.svg` 是可以一并导入的色卡。

## 建议先改哪几层

| 图层 | 用途 |
|---|---|
| 00 背景 | 画布背景；当前机位主要被城市地面覆盖，单独改它不会改变全部远景 |
| 01 地面 | 硬质地面，和绿地、水体分开 |
| 02 水体 | 湘江与其他水面 |
| 03 绿地 | 公园、洲岛及森林覆盖地面 |
| 04 道路 | 地面道路 |
| 05 建筑屋顶 | 建筑水平面、屋顶 |
| 06 建筑暖色立面 | 主要建筑墙面 |
| 07 建筑冷色立面 | 按现有 V4 分组的冷色墙面 |
| 08 树木 | 树冠可见部分 |
| 09 岸线与桥墩 | 河岸边缘、桥墩 |
| 10 桥梁 | 桥面 |
| 11 桥梁灯带 | 沿桥的线性照明 |
| 12 可隐藏窗格与窗灯 | 暖色／冷色、点亮／未点亮分别可选 |

每个材料组内包含 **主体区、过渡 25%、过渡 50%、过渡 75%、背景区**。过渡组由背景底色和带透明度的主体色叠成：改主体色时，把同材料组中的「主体色」「主体混合色」一起改为同一颜色，保留 25%／50%／75% 透明度。改背景城市颜色时，同时调整各材料组的「背景色」。

如果先只测试建筑：改 05／06／07；需要时再改 12 的灯光颜色。地面可以完全不动。

每组的「可隐藏_体块明暗」是黑色透明遮罩，用来维持屋顶、立面的体积感。先隐藏它可检查纯色搭配，确定颜色后再显示。不要把这层黑色也替换成建筑颜色。

## 给我回传什么

完成后，把两份改色后的 SVG 导出并发回来，或者发 Figma 截图并注明关键色号。请尽量保留图层编号。我会把配色对应回网页里的地面、墙面、屋顶、水体和灯光参数，再实渲校准。

## 文件性质与限制

- 这是**固定镜头的可编辑矢量配色稿**，不是截图包在 SVG 里。SVG 内没有 image、位图或外链资源。
- 使用当前 V4 河段机位的相机和真实场景几何；先做深度遮挡，再把可见材料区域转为闭合矢量路径。路径按材料合并，不支持逐栋建筑编辑或改变视角。
- 轮廓采样为 2160 × 1350，并在 0.6 像素容差内简化。极度放大会看到采样边缘，不是无限精度 CAD；小于一像素的树木、窗格可能丢失。
- 柔和边界为了便于配色分为三档过渡带。窗格和明暗为简化表达；没有复现实时阴影、雾效、Bloom、ACES 色调映射、水面动画及反射。
- 初始填色来自当前 V4 材质输入色，**不等于网页渲染后的屏幕颜色**。夜间文件会比实际夜景更平、更亮，这是去掉实时光照后的色彩研究稿，不是新的网页效果。
- 没有修改网页当前配色或模型。`preview-day.png` / `preview-night.png` 仅用于快速核对 SVG 的实际显示。
- 重复导出：在项目目录执行 `node --import tsx scripts/export-river-color-svg.ts`。这会更新两份 SVG 和 palette.json。

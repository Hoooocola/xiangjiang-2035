# 设计方案入口课程化 V2.5

基线：V2.4 已验证/已部署提交 `2b2b92e`，独立分支 `feature/course-based-design-proposals`。截至2026-10-31开始检查时，main为3eae236，#1/#4/#6/#7/#8仍未合并；本分支保留这些前置成果，不用旧main覆盖课程或地图功能。

## 同一数据、两种入口

顶部继续为图层 / 资料 / 设计方案 / 研究平台。设计方案现在直接浏览「2026 社会创新设计」，不再以三条概念DEMO作为主要内容。

- `src/student-works/courses.ts` 显式定义Course与StudentWork身份关系，目前只有一门课程，不显示空切换器。简介采用负责人V2.5任务提供的文字，不将其宣称为核验后的完整教学大纲。来源为既有Pinwall课程目录及已复核作品表。
- `StudentWorkShowcase` 同时承担正式地图课程目录与独立讲座展示；`StudentWorkExhibition` 同时承担两者的地点作品列表。用integrated布局变体，不复制第二套检索或页面。
- Course通过同一`visibleStudentWorks`检索、`statsForWorks`统计与`workPlaceIds`去重关系派生。当前全课程为24作品、13地点、4待定位；筛选时统计同步变化。多地点作品仅计一次，同一地点只计一次。
- 原四个研究主题及作品地点映射、封面、25份PDF与3条视频均未改。一个地点可关联多个主题，主题属于作品，不属于地点。

## 交互

按地点/按作品/未绑定地点目录共用搜索。标题、成员和原选址/注册地点都能检索；主题筛选使关联地点Marker带计数，其他地点降低UI权重，不修改AOI或场景材质。

定位通过原engine.focus/CameraRig，未定位作品只打开文字和媒体列表，不创建坐标、不运镜。多地点作品可选择已有关联地点。右侧采用90px方形封面纵向列表，左侧64px（窄屏60px），不轮播、不PDF内页替代封面。

关闭右侧保留主题与搜索；退出课程入口恢复进入前的地图视角/选择，并保留现实图层。资料、现实GIS目录和空间说明继续使用原协调器；Esc优先关闭当前实际面板。窄屏查看作品时隐藏左侧目录，关闭作品后回到同一筛选。

原 `?showcase=student-work` 独立演示仍可访问，也可从课程目录底部进入。两种入口使用同一数据、同一组件与动态统计。正式Proposal数据、关系、情景和资料入口保留；仅删除被替代的旧ProposalExplorer导航组件，不把StudentWork转成Proposal。

## 媒体与边界

PDF/视频复用StudentWorkReportLinks/StudentWorkMediaLinks及既有解析路由。点击报告在新标签页打开当前原站附件，源站不可用时回退到原作品页；没有PDF的作品可阅读原作品页。只有真实登记视频显示入口，点击原视频页面；无iframe/video、无自动播放或预加载。本轮未改变媒体身份、链接、安全白名单、授权或解析协议。

禁止范围均未改：`src/experience`、相机、AOI、材质、光照、粒子/雾、空间API、`src/places`、作品源表和地点映射、正式Proposal数据。

# 湘江 2035 空间信息系统 V1：第一阶段验收

日期：2026-10-27。按已确认的 1A＋2A＋3A＋4A 实施，接入现有 `/experience`，保留现有 Three.js 引擎。

## 本阶段交付

- 全局分类为基础地理、生态、文化、社会、经济、设计方案。原研究资料仍保留在资料、地点档案和对应研究主题中。
- 目录按子类型展开，图例与实际开启的子类一致。Demo 默认关闭，需明确开启。
- 点击对象显示简短解释，不移动镜头；“聚焦对象”才移动，“返回原视角”恢复进入焦点前的镜头并保留图层。
- 关闭图层、子类型、Demo 或切换范围时，会取消不再可见的选中对象；同时停止相关镜头运动。
- 四节导读：岸线 → 橘子洲大桥 → 100 m 等高线 → 橘子洲公园范围。允许自由操作中断导读。
- 基础材质与光照未在本阶段改动；选中对象的临时环境弱化复用现有能力。

## 数据及几何

`scripts/prepare-information-pilot.mjs` 从已有本地 OSM 与 DEM 数据生成 `src/atlas/pilot-features.json`，共 16 个样板要素：6 段岸线、1 座桥梁、3 个公园范围、1 组道路、5 组等高线。

- 岸线直接取自底图水域边界，裁切端点不闭合成虚构岸线。
- 桥梁绑定底图生成时保留的桥面与栏杆几何，采用其实际三角面和边缘强调，不使用包围盒冒充结构。原始数据为 OSM 线位；桥宽、高程及简化结构不是测绘成果。
- 公园 Polygon 保留内洞与分离区域，不称为湿地生态范围、保护红线或完整用地分类。
- 等高线来自约 150 m 分辨率本地高程网格，间隔 50 m。源高程数值与显示地形变换分离；不能用于工程或洪水判断。
- 新样板采用与显示表面一致的高度策略；线、面、模型与标签共享对象身份和空间锚点。
- 局部研究现场的对象轮廓改为模型网格边缘；该现场仍是未地理配准的 Mock，不因本次修改变成实测模型。

## 验收路径

打开 http://127.0.0.1:3002/experience ：

1. 图层 → 基础地理 → 橘子洲大桥：选中只改变解释与强调，镜头保持。
2. 点击“聚焦对象”：观察桥面与栏杆强调、环境弱化及简短来源说明。
3. 切换日夜；点击“返回原视角”：镜头恢复，图层保留。
4. 重新选中桥梁，关闭基础地理：对象焦点及解释清除。
5. “开始空间导读”：依次检查岸线、桥梁、等高线、公园范围；第四节不能继续到不存在的步骤。
6. 开启生态：湿地、生态廊道、观测数据明确待补充；不以公园范围替代湿地。

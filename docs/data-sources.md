# 地理数据、许可与表达边界

## 原始来源
- OpenStreetMap 官方 API：https://api.openstreetmap.org/api/0.6/
- 2026-10-20 取得湘江完整水域关系 `relation/8727387/full.json`。由核心地图查询识别关系 ID，并下载完整成员，非手绘河道。
- 核心地图与外围分块：112.930–113.005 E / 28.130–28.280 N（API 返回相交道路的完整节点，因此部分要素超出此框）。原始请求清单在 `data/osm/manifest.json`。
- 橘子洲 `relation/16734076`，对应湘江内环；建筑、道路、桥梁、公园直接使用 OSM geometry。
- 原始 JSON 在 `data/osm/`；浏览器读取 `public/data/xiangjiang.geojson`。运行 `node scripts/prepare-scene-data.mjs` 可重新生成。转换保留来源 ID、标签、真实坐标；排除已被转换器标记为 tainted 的不完整几何，并对水域逐层检查 relation → way → node 完整性。
- 分块查询只是获取来源，渲染没有为每个数据块设置矩形底座。

## 真实、估算、艺术化
| 内容 | 属性 | 限制 |
|---|---|---|
| 湘江主水域、洲岛 | 真实 OSM 轮廓 | 社区数据，非测绘级；岸线会随水位变化 |
| 橘子洲 marker | 已落在 OSM 岛内 | 为导览取点，不是测量标志 |
| 建筑占地 | 真实 OSM polygon | 城市覆盖不完整，不能补称完整长沙模型 |
| 建筑高度 | 优先 height / building:levels | 缺失时按建筑用途估算；视觉高度乘 1.65，最大 480m 场景高度；不是现状高度成果 |
| 立面、树木、桥墩 | 艺术化几何/程序化材质 | 不代表真实窗位、树种、植被数量或桥梁工程结构 |
| 主路、桥面 | 真实 OSM 线位 | 宽度与桥高为示意，未建完整桥梁精模 |
| 岳麓山地形 | 位置约束的连续示意山体 | 未使用 DEM，无真实高程精度；水面范围遮除山体裙边 |
| 铜官窑/昭山 | 研究范围参考点 | 不是遗址/景区边界 |
| 鹅洲 | **未校准 DEMO** | 沿用旧项目 112.874,28.057；UI 明确提示，不声称真实定位 |
| 地点叙述 | 导览文字 | 没有伪造调查数据、访谈、统计或研究结论 |

## 坐标契约
来源为 WGS84 经度、纬度（EPSG:4326），不是 GCJ-02，也不是 CGCS2000。当前采用以 112.965° E、28.195° N 为原点的局部等距近似：

```
x = (longitude − originLongitude) × 111320 × cos(originLatitude) / 100
z = −(latitude − originLatitude) × 111320 / 100
```

Three.js 为 Y 向上，X 向东，−Z 向北；1 单位 = 100 米。该近似用于局部三维视觉，整个研究范围有投影比例误差，不能作为精密测距。当前没有将 WGS84 标签冒充 CGCS2000。未来接入 CGCS2000（EPSG:4490 或相应投影坐标）需在数据入口依据元数据使用经过验证的坐标转换/本地校准，再投影为场景坐标；不能仅更改 CRS 名称。

## 覆盖边界
全段概览有连续真实河道与洲岛；高密度城市只覆盖长沙核心附近。全段未建完整沿岸建筑/道路/实测地形。外围使用真实体量逐渐淡出、距离雾与简化轮廓，不用随机城市或背景照片补齐空白。

## 水域完整性修复（2026-10-21）
视觉检查发现分块 API 返回的四条支流关系缺失成员，转换器会错误闭合，而没有始终设置 tainted。当前过滤 `16731304`（龙王港）、`5940862`、`2308803`（捞刀河）、`14964262`（靳江河）：分别缺失 1/44/35/5 个关系成员。尝试完整 relation API 时出现 TLS/连接超时，未伪造边界补齐。保留成员完整的湘江主水域 `8727387`。未来取得完整源数据后，生成器可自动纳入对应水域；需同步更新这一轮回归测试的快照约束。

最终派生数据包含 21,232 个要素：16,004 个建筑要素、5,032 条道路/路径、119 个公园、1 个完整主河道要素（内部包含多块水面和洲岛内环）。原始数据和派生数据库均随项目提供，不依赖浏览器运行时访问 OSM API。

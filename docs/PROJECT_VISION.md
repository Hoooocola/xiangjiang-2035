# 项目定位与目标

状态：依据现有实现、用户已确认任务与 V1.1 交付整理，2026-10-28。本文不新增产品决定。

湘江 2035 / 将来的江来，是将湘江沿岸地点、生态文化与社会研究、田野证据、问题和设计方案关联到空间的研究地图。宏观范围以铜官窑至昭山为主，核心空间阅读围绕长沙及橘子洲，保留鹅洲研究样板。

## 当前目标

- 用真实河岸、洲岛、建筑占地与地形提供空间上下文，说明估算和概念表达的边界。
- 让使用者完成“选择信息 → 镜头聚焦 → 空间高亮 → 理解内容 → 查看资料 → 返回探索”。
- 保留宏观、研究、地点三级预设和自由操作。
- 保持六类空间信息：基础地理、生态、文化、社会、经济、设计方案。
- 把已有资料、可追溯证据与概念方案区分开；缺少资料时明确提示或提供标注清楚的 Demo。

## 已实现和未实现

已实现：本地三维地图、场域目录、图层/对象/简明解释、资料和方案关联、概念研究现场、日夜切换；数据库路径已实现研究 Session 与 Field Record 采集/媒体关联。

未完成：真实全河段调查与完整 GIS 覆盖、生产认证和生产媒体存储、静态 Atlas 与数据库的完整同步、全部历史资料/洞察/方案的真实持久化工作流。

“2035”概念情景是讨论设计可能性，不是获批规划、建设承诺或预测。画面精细度不代表测绘精度；不得用艺术化补全宣称完整现状。

## 设计决策范围

保留当前引擎和主体验。Masar 是空间叙事、信息排版与视觉层级的参考，不是可复制的项目素材包。主场景的昼夜材质和 AOI 以当前已确认版本为准；保留实验页面并不意味着这些实验已经获准推广。

最终产品定位、重大地图/视觉/数据/相机/AOI 改动由负责人审核；协作者按明确模块边界提出 PR。

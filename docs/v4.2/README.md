## 原创模型与资源

用户于 2026-11-06 确认鹅洲模型为本人原创，可供本任务使用。原始文件只读保留于用户下载目录；仓库只含优化派生 GLB，不上传约 1.92GB 原模型、原 OBJ/MTL/独立贴图或临时提取文件。

- 原始精细模型：8 个块，14,523,255 三角形。
- 优化派生：414,039 三角形，549,438 UV 缝顶点；57,816 个源网格结构边段；单张 4090² JPEG。
- `ezhou-owner.glb`：19,570,592 bytes（18.66 MiB），不需要 LFS。
- 纹理 JPEG：6,069,738 bytes；GPU RGBA+完整 mip 估计 89,216,534 bytes，非显存实测。
- 10cm 坐标量化步长仅是存储精度，**不是简化总误差或测绘精度**。
- 源 metadata 为 EPSG:32649；离线 UTM49N → 现有局部切平面近似。高程基准未核实，42m 参考偏移用于既有场景显示，不代表已配准。主地图不嵌入本资产。
- 用户另给的低模 MTL 引用缺失贴图，未冒用精细模型贴图去替代其不匹配 UV。

详见 `public/data/visual-lab/asset-report.json`。离线工具 `scripts/visual-lab/prepare-ezhou.py`、`pack-ezhou.mjs`；后者使用现有 Three.js 自带 meshoptimizer，sharp 是构建机离线工具，可通过 SHARP_MODULE 指向已安装模块；不是新增产品运行依赖。首次恢复原始资产时需要用户的原始目录，普通克隆运行直接使用派生 GLB。

## 数据与渲染方法

- E-03 网络仍是既有 DEMO 图：2 个服务节点、12 个聚落代表点，8 个已连接、4 个未连接；来源原字段不变。选中设施高亮其 BFS 关联管段。管径和设施尺寸仅图解，不宣称真实设施。
- P-02 各剖面在 −400…+400m 以 5m 采样；同 `quarryHeight`，不夸大垂向。水下为未知；0 是模型水面相对零点，不是测量高程。−20m 幕底只是排版延伸。
- P-03 分区是新的 DEMO 多边形，不是法定或实测范围。面积用 4m 网格积分；冠幅覆盖为程序树冠投影求并集，不能视为真实植被覆盖或治理成效。坡度来自同一重建地形。
- 树叶单一共享实例几何，枝干/草合批；远处保留全部树木但减半均匀分布的叶片实例，技术态不用逐叶三角线框。细引线与 DOM 文本定位分离；按帧更新投影，碰撞/边缘/距离检查，实体态按对象遮挡稀疏更新，技术态允许 X-Ray 注释。
- 新 GLB 不从主地图载入。场景切换销毁旧几何、材质、纹理、实例缓存和 ImageBitmap；仅 CPU 源 JSON 保留既有缓存。透明层数量为语义图层预算，不等于逐像素叠加层数。

## 运行与验证

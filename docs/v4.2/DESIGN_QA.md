状态：**NEEDS_ITERATION / 待负责人审美验收**。技术检查通过与否另记，不构成视觉验收通过。

## 核心取舍

优先保留真实三维体积、已有模型与相机、真实的当前模型采样关系，以及 Masar 的低对比背景/高权重研究主体。没有拿概念板的形状、84m / 61% 等占位指标当作数据。没有生成图片代替浏览器场景。

E-03 从第一次全岛远景收紧为服务节点局部中景；管壁、纵肋、截面与设施体积可自由观察。P-02 修复地表遮挡剖面幕的问题，九张剖面形成连续空间阵列。P-03 从稀疏枝条加密为有叶冠的共享实例，并保留技术态枝冠骨架；不逐叶创建线框。

## 未通过的美术项

1. 原创航测派生在实体态仍有明显碎片、UV/地表细节与简化痕迹，离 Masar 的人工整理建筑和干净轮廓有差距。需要后续比较局部更高 LOD 与清理网格；不在本轮替用户假定其可接受。
2. 矿坑保留原重建曲面，坑壁仍可看见网格阶梯；不是照片级岩壁或真实测绘。技术阵列已有层次，但实体地表细节不足。
3. 程序树有分叉、非重复冠形和叶片实例，但没有达到 Celtis Forest 的植物资产、树种与地被真实度。
4. 标注具备投影、边缘、距离、碰撞与简化遮挡控制，复杂大幅度自由镜头仍需要人工检查，不能宣称完美遮挡。
5. 动态显影、剖面逐张展开和地下窗过渡留到第二阶段，不自动开展。

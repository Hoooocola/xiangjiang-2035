# V3.1 空间信息、地点定位与资源关系

基于 V3 的 51f5212，继续同一功能分支。未合并 PR #12 / #13，也未继承 WorkBuddy V2.8 的覆盖面、圆环或重复目录。原始毕业设计工作区不参与写入。

## 使用

图层标题为“空间信息”。移除五类目录内的旧“已有研究资料与示例”“阅读设置 / 范围·示例”界面；Atlas 记录、课程、地点、媒体和关联数据没有删除，仍通过顶部“资料 / 设计方案”及地点资料入口访问。

文化 / 社会 / 经济都有名称列表和“查看全部地点”。单点进入精读，概览按当前数据范围取景；圆 / 加号方框 / 圆角框分别代表三类节点，与既有研究地点菱形区分。符号热区44px，同主题屏幕距离44px以内可聚合；选中目标不被聚合吞掉。只显示hover / focus / selected的名称，不同时铺长标签。

点位投影在统一相机矩阵更新后执行，只写已有DOM的位置和状态；最多9个节点，没有每帧React更新、独立Mesh、Popup或第二渲染器。符号定位与内部形态分开。单点 / 全部 / 分析范围统一调用原CameraRig及informationPose，保留连贯过渡、交互中断、减少动态效果与返回原视角。未知ID、缺失或超出地图范围的坐标拒绝运镜，显示明确提示。

选文化地点 → **分析周边资源**。默认2km，另有500m / 1km / 3km：当前DEMO设施样本较稀疏，橘子洲1km内无命中，不因此移动或补造样本。只突出范围内样本，并显示局部道路参照与贴地细边界。切换地点 / 半径会重新计算，关闭文化图层、清除图层或正常地点导航会移除分析。清除分析可保留地点；返回原视角恢复进入点位定位前的镜头。

原三幕、B范围扫描和可拖动C透镜保留。日间B仅提高选中像元的蓝灰明度对比、类别纹理和一个原生像元级细边；夜间配方与C的原始分类颜色保持V3。没有修改基础材质、水体、AOI或源像元。目录和精读衬底使用共享主题变量、横向渐变加上下mask渐隐，装饰层pointer-events:none，无backdrop blur；正文独立滚动，不把滚轮传给地图。

## 数据真实性与计算

完整15项状态、数据文件、来源、数量、范围、交互和缺口见 [DATA_STATUS.md](DATA_STATUS.md) 与 [data-inventory.json](data-inventory.json)。生成方法：`node --import tsx scripts/audit-exploration.ts`。这是离线检查，不下载或修改资料。

- 真实岸线、道路、DEM与WorldCover继续复用原文件。GBIF100条有API而没有三维聚合，水质30条无核验坐标，不上图；水质不是历史水体范围。
- 3个文化地点沿用注册坐标与精度说明，是地点索引，不是完整遗产普查。
- 公共服务 / 商业分别3个固定DEMO点，未挪动。新增定位和分析能力不把样本变为真实设施。
- 步行关系仍为近邻路段示意，没有可路由的完整步行图。新功能明确叫直线资源分析，不叫步行可达性。

距离为WGS84球面大圆距离，地球平均半径6,371,008.8m，中心到节点 ≤ 所选半径。现有源节点ID唯一，按ID组织结果，不按像素圆或显示面积统计。边界用球面目的点公式采样64段；道路按现有局部投影的点到线段距离选作参照，不参与设施数量计算。

橘子洲测试结果：500m / 1km为0个服务、0个商业；2km为2 / 0；3km为3 / 2。换岳麓山 / 开福寺结果按其坐标计算。0不是设施不存在，数量差异不是服务不足；问题文本包含当前地点、半径和命中数，只提出需要真实调查验证的线索。没有随机数值、伪造人口或时间序列。

## 文件和核心边界

UI为 `layer-panel`、`resource-explorer`、`exploration-tools`及其CSS。`experience.tsx`只协调状态、精读互斥与既有入口。

`src/exploration/relations.ts`为纯距离 / 结果 / 边界 / 聚合逻辑；`markers.ts`为限量DOM投影。`render.ts`增加日间B识别、一个分析范围细线批次及邻近道路参照，关闭时dispose；V3原来3个5px节点Points批次由可发现的DOM符号替代。`engine.ts`只挂接这一模块和有界的定位接口，仍使用同一个CameraRig、renderer、场景和原资产。没有改CameraRig算法、地理投影、AOI、照明或后处理架构。

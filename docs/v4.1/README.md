## P0 最终行为

- 全域地点、文化/社会/经济和两处研究场景复用菱形 SpaceMarker。44px 命中区域；只有内部符号改变视觉，不给定位容器的 transform 添加插值/持续动效。
- HTML 锚点来自地理/局部模型 world coordinates，投影使用当前 camera matrices、Canvas CSS 尺寸和 Overlay 原点/缩放。DPR 不再参与 CSS 坐标。局部标签有36px聚合和侧栏遮挡过滤，并提供对象列表入口。
- 关闭研究面板：停止当前运镜、隐藏 UI，保留模型、相机和分析状态。退出引导：停止自动镜头，留在场地。重置：当前场景预设。返回湘江全域：显式释放局部模型并转到全域。地点简介关闭也与“返回原视角”分开。
- 同一 CameraRig 处理主图/两处场景。wheel deltaMode 归一化，连续触控板事件累积目标距离，cursor-plane dolly，FOV/视距相关平移，保留边界/地面约束、手动中断、减少动态偏好。相机矩阵原来已有 updateMatrixWorld，不把它错误归因为新修复。
- 引导距离不反复拉远；鹅洲约37.24→11→9.4→8.2→5.5→5.5单位，矿坑15→11.5→10→9.4→8.8→8.8→8.8。一个单位100m；姿态与研究内容对应，不改变地理位置。
- 首次默认日间；用户明确切换后 localStorage 继承到矿坑和主图，统一主题组件。旧风格帧实验不推广。
- 图层、资料、地点/研究阅读、课程、地点/镜头/关于目录及研究场景共用 SidePanelShell：390px桌面宽、固定标题、滚动正文、固定底部，窄屏自适应。不靠大面积渐隐排版，不增加全屏玻璃。
- 所有运行时用户可见“坪塘深坑”改为“坪塘矿坑”；内部 quarry 路由/ID 保持。

## P1 模型与数据

鹅洲保留真实岸线、可追溯 OSM 道路/足迹及已有 context 位置。去除局部重复粗体量，加入多种屋顶、立面、窗门、少量院落附属表达；三类树冠/灌木批次、地表微起伏、岸坡和低频不规则耕作空间。建筑缺失高度、细节、植被和农田仍为 RECONSTRUCTED，不能作为现状调查。

矿坑独立模型：非规则坑缘、分段岩壁/台阶、局部岩石着色、稀疏植被、平面水色层次；不是水深图。增加未配准 DEMO 道路图、入口和少量环境体量，新闻未证明已建成任何道路。准确坑址/高程/水深仍未知，coordinate=null，未错误嵌入湘江。

12个代表点均有 ID、固定DEMO坐标、空间类型、模拟服务单元、关联道路索引/服务节点和待调研证据，总66服务单元不是实际户数。点击后微调相机、高亮最近的关联建筑及图路径。BFS 结果驱动8/4比例图；移除边立即改变结果和三维管线，非真实设施或污染结论。

矿坑剖面161点/5m步长，示意坡度24m陆地采样，路径2m采样，Dijkstra平面路网距离。剖面Hover→地形采样光标；坡度类别Hover→相应样本；路径Hover/点击→线路/属性；入口边可移除。分析共享同一 quarryHeight，不硬编码结论，不输出准确车程/步行时间或安全风险。

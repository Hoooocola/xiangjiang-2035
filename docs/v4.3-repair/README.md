## 网格诊断与取舍

旧派生使用约 2.5% 目标面数、2.5% 相对简化误差及 10cm 位置量化。检查发现 1,442 个量化退化面、2,050 个最长边超过 10m 的三角形，p99 最长边 8.79m、形状比 31.67；过度简化放大了扫描植被/屋缘的碎裂。顶点索引范围有效，位置有限，坐标比例正确；UV 接缝保留、法线重算。实体采用烘焙纹理的不受光材质，法线不是整片破碎的解释；旧局部剖切只在小窗口生效。未通过全局雾、模糊或透明度隐藏模型问题。

新派生基于保留的原创中间网格，6% 目标、0.08% 相对误差、5cm 量化，剔除量化后退化面。输出 1,470,353 面 / 44,832,532 bytes，位置非法/越界/退化面均为 0；超过 10m 的三角形降至 308，p99 最长边 4.33m、形状比 13.69。纹理仍为同一 4090² 合图，未增大纹理分辨率。原始 1.92GB 文件、旧 GLB、V4.2 路径完整保留。

这是质量优先的局部派生，不是精密测绘模型；近距离树冠、屋缘仍有扫描噪声与烘焙光照，不能承诺所有尺度无瑕疵。新模型比旧 GLB 约多 25MB，仅在研究页面按需加载，不进入主地图首屏。未来若需移动端更快冷加载，应在同机位质量检查下增加独立 LOD，而非恢复旧过度简化。

## 水位校准

网格重新由可见的新模型提取，记录其 SHA-256；10m 最低包络、第五百分位相对零点、江水连通与缺失格最近邻填补方法未变。新相对零点约 −7.724m（内部显示基准，非水文站高程）；79 个格需填补。默认：淹没 10.30ha / 警惕 3.86ha / 稳定 77.87ha，分别约 11.2% / 4.2% / 84.6%。默认受淹代表点 0/12 是计算结果；高水位情景会改变分类、设施、道路与统计，不为演示效果捏造人数。

低包络包含扫描误差与植被，不能作洪水预报、房屋风险或工程安全判定。辅助岛底仅填补 OSM 岸线与照片网格之间的显示空隙，不参与统计。背景 DEM 的压缩高程不替代研究网格。

## 最终表现

- E01–E03 默认 `reveal`。保留实体与技术手动切换；局部显影具有独立的日夜背景适配，不把整个场景强制变为技术模式。
- E01：原创模型低对比、低饱和保形；原岸线轮廓与大桥结构强调，两岸估算背景弱化。
- E02：12 个聚落及 3 个游憩点附近的局部材质与结构显影，选中点紫色强调。既有 66 个服务单元不变，标签含游憩节点，非研究地物降低竞争。
- E03：三类分区来自原连通分析结果，使用低透明度三维分区注记、边界和原动态水面。选择水位仍重新计算统计，不手画结果；默认仍为 5m / 10.30ha 淹没、3.86ha 警惕、77.87ha 相对稳定。
- 结构线复用派生模型的约 9,741 条特征边，按研究范围在 shader 内显隐；未开启全模型 wireframe、重建或再次简化资产。E03 增加 3 个批次的分区注记，仅参数变化时构建。
- E04/E05 不启用新的局部表现；原设施 X-Ray、选中剖切、镜头保持与四情景计算保留。
- P01–P07 的默认模式和三维资产完全保持本轮之前的状态。

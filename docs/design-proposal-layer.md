# 设计方案图层接入与右侧详情修复

2026-10-29。沿用 `demo/student-work-showcase` 功能分支，不合并 main。

## 当前入口

首页 `/experience` → 顶部“图层” → “设计方案”。开启该图层显示课程作品地点标记；展开后选择“浏览课程设计作品”，进入主题、搜索与地点作品目录。无需额外链接，也无需开启 DEMO。旧 `/experience?showcase=student-work` 链接兼容为默认开启设计方案图层。

## 图层叠加

设计方案复用同一 layers 状态，不再作为独立页面模式。开关不会关闭其他图层或收起图层目录；可继续勾选地理、生态、文化等类别，再进入课程作品目录。仅关闭设计方案时，其余类别保持开启。原有普通地点标记、地图导航及研究平台入口保留。

引擎创建时一次性传入已存在的导航点集合，避免开关图层重建地图；额外课程导航点未开启时隐藏。不修改地点坐标、AOI、相机核心或底图材质。

## 详情互斥

截图中的叠层来自旧作品详情未随空间对象选择关闭。现在点击岸线等对象会清除作品详情选择，点击作品会清除旧空间对象说明。统一 `activeSceneDetail` 决定右侧显示哪一个详情，保护作品列表、空间解释、地点资料和资料库不重叠。已开启图层不受详情切换影响。

## 验证

- TypeScript、相关 ESLint、diff 检查通过；隔离副本 webpack 生产构建通过。
- 完整测试 109 通过、26 数据库测试按既有配置跳过。新增关闭 DEMO 时仍有课程方案入口，以及同时存在作品/岸线选择时只显示岸线详情的回归测试。
- 实际浏览器：六个图层同时开启，地理、生态、文化公开对象仍在 visibleObjects 中；进入课程目录后保留全部六个 layers。
- 复现“潮宗街作品 → 湘江岸线·岸段2”：保留地理、设计方案、社会、经济四个图层，右侧只存在岸线空间解释，课程列表数量为 0。

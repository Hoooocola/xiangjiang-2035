# 湘江场域清单

来源：实际查看单页 PDF《湘江场域标注与分类》，原文件 Downloads/Frame 1.pdf；归档在 docs/references/xiangjiang-site-classification.pdf。图上 56 个标注，不把图例中的“等”推断成新增地点。类别根据图例及名称性质整理；PDF 没有逐点分类符号，个别类别为编辑归类，后续可核实。

核验含义：open-gis = 匹配本地 OSM 开放地理对象，并非测绘认证；point-only = 仅点位，不能推出边界；approximate = 既有项目近似点；unverified = 不产生坐标/亮区。未从 PDF 像素生成经纬度。

23 个可配置 Focus Area：20 个开放 GIS 面 + 3 个明确 Approximate 视觉包络。其余 7 个点保留目录位置但不伪造范围；26 个条目尚待定位。公开 Overpass 补充核验本次返回 406/超时，后续可补全。

## 重要解释

- 中南林、大学城、湖师大科创港、湖大科创港、湘潭理工等保持原图简称，不自行补成未经核实的机构全名。
- 霞凝港（社区）包含设施/社区语义，本版暂归滨水港口并标待核验；不主张行政社区边界。
- 麻谭山保留原图字形，并记录可能的麻潭山别名。
- 烈士陵园与烈士公园不是同一标注，匹配湖南革命烈士陵园而非市中心烈士公园。
- 文昌阁、南门口、鹅羊山检索结果存在同名车站，排除后暂不赋坐标。
- 铜官窑、鹅洲、昭山仅继承项目既有近似坐标，配置的上下文包络是视觉概念范围，不表示遗址/洲岛/景区真实边界。
- 六类场域与 Context/Resources/Evidence/Findings/Proposal 五层研究内容相互独立，通过稳定 siteId / placeId 关联。

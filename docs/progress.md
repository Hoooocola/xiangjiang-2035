# 六阶段执行记录

## Stage 01 — Reference Analysis
已完成实际网站与官方案例的浏览器观察，保留 10 张有效参考状态；最初失败和窄屏限制已记录。参见 reference-analysis.md。

## Stage 02 — Legacy Audit
已检查路由、依赖、Leaflet、数据库、演示数据、静态资产。原目录无 Git，创建旧版提交 3bf2d3e 与 legacy-before-3d 标签，在 feat/xiangjiang-immersive 分支开发。保留全部研究功能。

## Stage 03 — Visual Scene Prototype
从 OSM 官方 API 获取完整湘江水域、橘子洲轮廓及城市数据。完成 Three.js 多边形水面、带内洞河道、建筑挤出、道路、桥梁、植被、岳麓示意地形；先做场景再接 UI。浏览器第一轮发现俯视过高、水纹重复、桥面背面朝上和山体裙边进入水面，已修正并重新截图。

## Stage 04 — Camera & Interaction
三组镜头均实际截图：沿江纵深、隔江望城、洲岛全貌。选择沿江纵深作为默认，前者较能同时表达江道纵深和东岸城市；隔江镜头可比较两岸，第三组保留作地理阅读。完成平移、旋转、滚轮、键盘、双指逻辑、阻尼、巡游、输入打断、地点聚焦、返回、全段与重置。橘子洲 marker 经数据测试确认落于真实洲岛 polygon 内。

## Stage 05 — UI & Motion
独立 CSS Module，全屏场景、项目字标、开始探索、精简导航、日夜开关、空间 marker、地点面板、镜头选择及数据说明。开场文字退出、面板进入、渐变日夜与统一相机缓动。无数据库新增功能。

## Stage 06 — Polish & Optimization
追加外围真实城市数据，窗口 shader、建筑外围淡出、距离雾、远景简化体量渐变、实例化植被与桥墩、静态阴影缓存、DPR 上限、标签边缘避让、可中断动画、WebGL 错误提示与资源释放。执行生产构建和多视口视觉检查。最终结果及未达标项以 delivery.md / visual-review.md 为准；不将本次原型宣称达到 Masar 完整资产制作水准。

### 最终复核
生产版通过构建、类型检查、11 项测试；数据库26项未启用。完成1440×900、1920×1080、390×844浏览器检查。修复支流关系不完整造成的错误闭合、焦点导致主容器滚动裁切。两轮概览/地点切换后渲染器geometry计数稳定在13；此结果不替代长时间内存测试。交付文档已整理，原项目内容保持可恢复。

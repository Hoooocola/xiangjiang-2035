## 视频性能与资源生命周期

| 状态 | 地图内播放器 | 观察 |
|---|---|---|
| 未启用课程图层 | 0 | 保持原地图渲染。 |
| 进入课程模式、未点击视频 | 0 | 列表只有封面和普通外链；没有 video/iframe/source 或媒体 preload。 |
| 打开视频原页/原平台播放器 | 0 | 播放器存在于外部标签；原地图状态保持，地图没有新增解码实例。 |
| 关闭视频/返回地图 | 0 | 外部视频标签关闭；没有隐藏播放器留在地图 DOM。 |
| 切换作品与地点 | 0 | 每条视频入口属于对应作品，列表上下文与统计更新；外部链接不重建地图或发出镜头动作。 |

自动化与实际DOM检查均确认不创建站内播放器、不自动播放，不进行视频首屏预加载。前台定点观测示例：课程总览约23fps、裕湘列表约21–22fps，操作可响应；早期后台标签和并行构建期间出现0–1fps节流读数，不能混作前台性能结论。不同相机位置的三角面数量也不同，因此这些单点数值不是严格受控性能基准。

当前浏览器工具没有可用的堆内存或网络瀑布接口，未给出精确内存增减、首屏时延或跨设备帧率保证。能够直接验证的是：地图始终0个视频/iframe播放器，关闭外部播放器后不残留实例；原生视频在独立标签页完成解码。正式讲座仍应在目标笔记本和现场网络预演。

## 失败、授权与回退

- 视频仅采用原页外链；3条均未核验额外嵌入许可，不生成 iframe，不声称获得重新托管许可。
- 可选直接附件路由仅接受已登记作品/视频ID，页面8秒及资源5秒超时，页面读取上限1MiB；附件只进行1字节Range校验，随后直接重定向原平台。失效/超时提供来源页，不代理视频正文。
- PDF原入口继续兼容；多报告可按附件ID选择，附件不在该作品页时回退原作品页，不跨作品拼接地址。
- 版权仍归原作者；用户已授权课程资料与项目的 GitHub 团队共享。未提交密钥、.env、成绩、数据库或用户个人田野资料。
- 若需回退，撤销本次V4提交即可恢复基线；保留老师修订表的核对记录用于后续数据集成，不改写旧分支历史。

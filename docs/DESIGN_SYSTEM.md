# 地图与 UI 设计原则

2026-10-28；以当前实现和明确获批约束为依据。此文档不重新选色，不宣称风格帧实验已被接受。

## 地图视觉

- 保留 Three.js、自定义相机和现有功能，日夜默认进入暗模式。
- 湘江水体、洲岛、山林和城市保持可辨识的材料分工；不能为对标沙漠城市而把全场景改成米色。
- 主体、过渡、外围形成连续层次；保留远岸建筑/植被上下文。AOI 不是硬裁切开关。
- 使用 `materials.ts`、`lighting.ts` 和 `aoi/` 中当前值作为主体验基线。`style-frame`/`style-frame-v4` 为实验入口，不自动同步到主场景。
- 用户已撤销上一轮“将建筑灯光实验合入当前版本”的修改。未经新授权不得重新推广该实验。
- 重大视觉变化须固定镜头昼夜对照、三个尺度检查和负责人审核，不能用自由镜头截图掩盖差异。

## 空间符号与阅读层级

点、路径、区域和三维对象按语义表达，不强制全部线框。地点菱形维持已有结构；内部动效和世界定位分离。目标高亮保留必要场景，避免隐藏整座城市。图层与标签使用同一状态规则。

小地图是线条式空间定位；紫色框采用矩形视野提示，不能当作透视地面足迹。保持主地图与小地图状态联动。

## V1.1 信息 UI

- 顶部操作行、图例、标签保持共享规则。
- 左侧为“阅读这段湘江”目录：中文主分类、英文辅助、小序号、细线、明确展开/显示开关，具体对象按 Active 小菱形强调。
- 右侧是场景解释：类别、标题、1–3 句介绍、必要指标、来源/DEMO 和详情入口。作者、年份、精度等按需展开。
- 局部渐变用于保证文字可读；不再依赖两张大型矩形卡片。
- 窄屏选择后收起目录，底部说明可滚动，保证目标仍在可用视口中。
- 使用现有 CSS 变量与 `information.module.css` 排版；不在组件各自复制一套语义颜色和间距。

## 交互与动画

点击具体目录对象自动聚焦；分类展开/开关不移动镜头；直接地图选择不强制移动。几何类型决定取景，约 1–2 秒的过渡随距离变化。正文接近落位时淡入，不能先开大资料面板遮挡目标。

相机统一控制、可中断、连续点击只执行最新目标、可返回之前视角。支持键盘、可访问名称、可见焦点和减少动态效果偏好。任意 hover/active 调整都要同步考虑昼夜和高亮对象。

## 数据表达

DEMO 状态不能仅靠颜色区分，必须有文字；年份区分编制时间与真实调查时间。面范围标明概念、近似或公开几何；指标必须有值、单位、统计范围和时间，没有依据就不填造数值。

## V2.4 已授权结构更新（2026-10-31）

首次选中地点默认Layer B编辑式介绍，不显示FIELD NOTES大卡；来源和坐标渐进披露，长文Layer C需要明确操作。资料索引采用标题列表与可展开摘要。现实GIS导航为五类，设计方案与资料并列；StudentWork仍为独立演示，Proposal数据契约保留。氛围可以关闭，减少动态效果优先；未重做昼夜材质。昭山采用明确非山界的DEM视觉焦点，近似点精度须显示。

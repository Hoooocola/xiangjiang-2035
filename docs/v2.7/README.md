## 边界

课程年份、Excel导入、地点坐标、多媒体关系没有改动；旧24本地封面不变。27个新增封面只刷新公开原站URL，来源变成另一张图时拒绝自动替换，保留明确缺失状态。服务器只请求公开元数据，不绕过访问控制或把图片重新托管。第三方仍可能超时/失效。

阅读层用experience.module.css共享主题变量，遵循现有地点/图层/资料的文字层级、细线、紫色强调及局部渐变；不重新设计其他目录。只装饰背景渐隐，独立滚动和44px操作目标保留。窄屏选择作品后仍使用现有左右互斥行为。

场景只修改可关闭atmosphere模块，不改地图核心配色、建筑材质、AOI、GIS、CameraRig或曝光。局部云雾是程序化视觉近似，不是实测天气。标准/轻量/关闭和减少动态效果保留；少量云层，不增加纹理下载、重后处理或点光源。

# 2026-10-22 第三轮：沿江分层与导航

本轮按用户确认的自查方向实施，并加入用户指定的线条小地图，删除探索阶段“山·水·洲·城”文案。预览为 http://127.0.0.1:3001/experience，桌面右下角版本号为 SPATIAL EXPERIENCE 03。

## 可见变化

- 日间改为冷中性灰白背景、蓝绿江面和灰蓝建筑，移除暖米白光照。
- 取消长沙核心段的纵向强调限制。铜官窑至昭山按距真实河岸的距离统一决定重点材质；原有建筑和新增外围建筑共用窗格、昼夜及选中材质。背景建筑、道路、植被仍保留。
- 夜间背景压为深青色，重点建筑增加窗光与明暗层次；桥梁灯带只用于跨水桥段。
- 加入真实河岸几何生成的极简小地图，左北右南，紫色多边形随镜头更新。可以点击地图定位，也能通过三个地点按钮跳转。
- 左下收拢昼夜、小地图与工具；右下用两枚菱形入口组织全段与地点探索。镜头按钮折叠，地点说明改为较轻的浮层，移动端列表可滚动。
- 橘子洲选中范围着紫色；地点返回、巡游、全段及预设切换清理旧选择状态。自由定位不再显示“长沙核心河段”。

## 数据与模型边界

建筑仍由离线 OSM / Overture Maps 数据在本地生成，不是在线建筑模型 API，也不是逐栋人工精建。共 158,242 个建筑体量，1,331 个有高度来源，其余仍按既有规则估算。外围主要是轮廓推导的简化体量。树木 42,023 个，按地形与林地范围布置。

本轮修复“有数据却因材质规则而整段变白”的问题，没有新增建筑数据源，不能据此声明每个沿岸地点均无缺漏。铜官窑、昭山仍是范围参考点；鹅洲仍待坐标校准。昭山视角的真实林地和低密度区域不会填入虚构高楼。

与 Masar 的差距仍在精细地标、立面、铺装、植物资产、局部灯光及真实水面反射。当前摄影范围更大、建筑更小，不能把 UI 与分层的改进当作同等级模型品质已达成。
